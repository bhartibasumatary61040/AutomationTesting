# 🚀 Automation Testing Framework | Selenium + Java + TestNG

This repository contains a complete **Automation Testing Framework** developed using **Selenium WebDriver, Java, TestNG, and Maven**.  
It follows industry best practices like **Page Object Model (POM)** for maintainable and scalable automation.

---

## 📌 Tech Stack

- Java  
- Selenium WebDriver  
- TestNG  
- Maven  
- Page Object Model (POM)  
- ChromeDriver  

---

✔ Page Object Model design pattern
